# Building ThreadSpec.org

The site is static HTML generated by the scripts in `build/`. Do not edit the
generated `index.html` files by hand: change the data or the templates and
rebuild, otherwise the next build overwrites the edit.

```bash
python3 build/build.py   # writes every page, sitemap.xml and llms.txt
python3 build/check.py   # quality gate, must print "all checks passed"
```

Python 3.12 or newer, standard library only.

## Layout

| File | Purpose |
|---|---|
| `build/tables.py` | Values taken from standards, each with its source |
| `build/threads.py` | Thread lists and the dimensions computed from them |
| `build/drills.py` | Number, letter, fractional and metric drill sizes |
| `build/content.py` | Hand-written notes on where a thread is used |
| `build/svg.py` | Inline SVG diagrams |
| `build/shell.py` | Page shell, head scripts, structured data, helpers |
| `build/detail60.py` | Pages for metric and Unified threads |
| `build/detailpipe.py` | Pages for NPT and BSP threads |
| `build/hubs.py` | Chart pages, tap drill chart, home page |
| `build/guides.py` | Guides, calculator, identifier, about, privacy, 404 |
| `build/check.py` | Data and page checks |
| `assets/site.css` | The only stylesheet, hand-written |

## Rules for the data

1. Diameters of 60 degree threads are computed, never typed in. `check.py`
   compares them with values printed in ASME B1.1, ISO 898-1 and ISO 965-2.
2. Tabulated values (NPT, BSP, limits of size, clearance holes, strengths)
   live in `tables.py` with a comment naming the standard and table.
3. Tap drills are conventions. Each table in `tables.py` says which published
   chart it follows. Where no chart lists a size, the page says how the drill
   was chosen.
4. Strength and clearance tables are shown only for sizes the standard covers.
5. Usage notes in `content.py` list only well-established uses. A thread
   without a note gets none.

## Sources checked (September 2026)

| Data | Source |
|---|---|
| Metric pitches and choice | ISO 261:1998 Table 2 |
| Metric basic dimensions | ISO 724:1993 and ISO 724:2023 |
| Metric tolerances | ISO 965-1:1998, checked against ISO 965-2:1998 |
| Metric stress areas and strength | ISO 898-1:2013 Tables 3 to 7 |
| Metric clearance holes | ISO 273:1979 |
| Metric tap drills | tables citing ISO 2306 and DIN 336, Guhring chart |
| Unified series, limits, stress areas | ASME B1.1-2003 Tables 1, 2, 6 to 8 |
| Unified tap drills | Machinery's Handbook 28, Starrett Bulletin 1214 |
| Inch clearance holes | ASME B18.2.8-1999 (from two reproductions) |
| Inch bolt strength | SAE J429 (from manufacturer data sheets) |
| NPT | ANSI/ASME B1.20.1-1983 Table 2 and Appendix |
| BSP | ISO 228-1:2000 Table 1, Emuge tap drill chart |

Known gaps: the 2013 edition of ASME B1.20.1 re-rounded some values in the
last digit and was not available; ISO 2306 and DIN 336 were not read directly;
G1-3/8 is not in ISO 228-1 and comes from manufacturers' tables.

## Adding a thread

Add it to the list in `tables.py` or `threads.py`, add its tap drill, rebuild
and run the checks. The sitemap, charts, identifier data and internal links
update themselves.

## Third-party scripts

The consent defaults, AdSense, Google Analytics and Ahrefs tags are in
`HEAD_SCRIPTS` in `build/shell.py`. Pages marked noindex get no ad script.
